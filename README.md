# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт учебного интернет-магазина противогазов, защитной экипировки и сценического костюма чумного доктора.

На главной странице представлены 3 популярных товара, в каталоге — 9 товаров с изображениями, краткими описаниями, ценами и кнопками заказа. Для противогазов, костюмов и аксессуаров созданы отдельные страницы категорий.

## Ссылка на опубликованный проект

GitHub Pages: [открыть сайт](https://ImBread300.github.io/kr1-html-css-shop/).

## Локальный запуск

Скачайте проект или клонируйте репозиторий и откройте `index.html` в современном браузере. Установка зависимостей и сборка не требуются. Для разработки можно использовать Live Server в редакторе кода.

## Постановка контрольной работы №1

Тема контрольной работы №1: «HTML и CSS: разработка многостраничного сайта».

В рамках контрольной работы необходимо разработать многостраничный HTML/CSS-сайт интернет-магазина или каталога услуг.

Проект должен включать:

- главную страницу;
- страницу каталога;
- страницу карточки товара или услуги;
- страницу оформления заявки;
- страницу контактов;
- семантическую HTML-разметку;
- внешний CSS-файл;
- базовую навигацию;
- оформление основных блоков страницы.

Сейчас реализованы 9 страниц: главная, каталог, контакты, три категории, подробные страницы ГП-7ВМ и костюма «Венеция» и страница доставки и оплаты. Заявка оформляется в модальном окне на страницах с товарами. Отдельная страница оформления заявки пока не создана.

## БЭМ-структура проекта

- `site-header` — шапка, внутренний контейнер и логотип;
- `site-nav` — меню с элементами `__list`, `__item`, `__link` и модификатором `__link--active`;
- `breadcrumbs` — хлебные крошки с элементами `__link` и `__current`;
- `site-main`, `hero`, `section` — основная область и разделы страниц;
- `products-grid` — общая сетка товаров на главной и в каталоге;
- `product-card` — переиспользуемая карточка с элементами `__image`, `__content`, `__category`, `__title`, `__description`, `__price`, `__old-price`, `__current-price`, `__condition`, `__actions`, `__button`, `__details`, `__badge`, `__specs` и модификаторами `--featured`, `--compact`, `--horizontal`, `--sale`, `--markdown-medium`, `--new`;
- `category-nav` — переходы между категориями с активным состоянием `__link--active`;
- `info-grid`, `info-card` — сетка и информационные блоки страницы доставки;
- `catalog-layout`, `catalog-products`, `catalog-filters` — макет каталога, товары и фильтры;
- `order-dialog` — модальное окно оформления заявки;
- `order-form` — форма с элементами `__field`, `__label`, `__input`, `__select`, `__textarea`, `__checkbox`, `__hint`, `__actions`;
- `button` — кнопка с модификаторами `--primary` и `--secondary`;
- `advantages-list`, `aside-info`, `success-message`, `back-to-top` — дополнительные компоненты;
- `reviews`, `review-card` — список отзывов и отдельная карточка отзыва;
- `site-footer` — подвал сайта.


## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root`;
- единая шкала отступов;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus-visible`, `:disabled`;
- визуальная подсветка ошибочных полей через `aria-invalid`;
- структурированный файл `css/style.css`;
- применение Flexbox для компоновки элементов;
- позиционирование элементов с помощью `relative`, `absolute`, `fixed` и `sticky`;
- одинаковые квадратные области изображений с сохранением пропорций через `object-fit: contain`;
- автоматический перенос карточек в Grid-сетке в зависимости от доступной ширины.


## Реализованные элементы интерфейса

- кнопки заказа на главной, в каталоге, категориях и на страницах ГП-7ВМ и костюма «Венеция»;
- модальное окно с формой заявки и передачей выбранного товара;
- отображение названия выбранного товара в форме каталога;
- автоматический выбор темы «Заказ товара»;
- поля формы: имя, e-mail, телефон, дата, тема, комментарий, согласие;
- базовая HTML-валидация;
- базовая JS-обработка формы;
- сообщение об успешной отправке.

После корректного заполнения форма очищается, окно закрывается и появляется сообщение об успехе. Обработка выполняется в браузере: сервер не подключён, данные заявки не отправляются и не сохраняются.

В каталоге работают фильтры по категориям и диапазону цены. Выберите условия и нажмите «Применить»; без выбранных категорий учитываются все товары. Можно выбрать несколько категорий, сбросить условия и увидеть количество найденных товаров. Если результатов нет, отображается пояснение. Сортировка пока не реализована.

В проекте используются:

- Flexbox для основного меню;

- CSS Grid для страницы каталога с фильтрами и списком товаров.
