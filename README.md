# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Ссылка на опубликованный проект

GitHub Pages: https://ImBread300.github.io/kr1-html-css-shop/

## Постановка контрольной работы №1

Тема контрольной работы №1: «HTML и CSS: разработка многостраничного сайта».

В рамках контрольной работы необходимо разработать многостраничный HTML/CSS-сайт интернет-магазина или каталога услуг.

Проект должен включать:

- главную страницу;
- страницу каталога;
- страницу карточки товара или услуги;
- страницу оформления заявки;
- страницу контактов;
- семантическую HTML-разметку;
- внешний CSS-файл;
- базовую навигацию;
- оформление основных блоков страницы.

## История выполнения

- Практическая работа 1: создан Git-репозиторий, опубликован проект на GitHub Pages.
- Практическая работа 2: создан HTML-каркас стартовой страницы и выполнено базовое CSS-оформление.
- Практическая работа 3: добавлена форма заявки, модальное окно и базовая валидация.
- Практическая работа 4: добавлены CSS-переменные, состояния интерфейса и упорядочена структура стилей.
- Практическая работа 5: создана многостраничная структура сайта, добавлены единая навигация и якорные ссылки.
- Практическая работа 6: добавлены Flexbox-навигация и Grid-раскладка карточек и каталога.
- Практическая работа 7: выполнен рефакторинг CSS-стилей по методологии БЭМ.

## БЭМ-структура проекта

- `site-header` — шапка, внутренний контейнер и логотип;
- `site-nav` — меню с элементами `__list`, `__item`, `__link` и модификатором `__link--active`;
- `breadcrumbs` — хлебные крошки с элементами `__link` и `__current`;
- `site-main`, `hero`, `section` — основная область и разделы страниц;
- `products-grid` — общая сетка товаров на главной и в каталоге;
- `product-card` — переиспользуемая карточка с элементами `__title`, `__description`, `__price`, `__button`, `__badge` и модификатором `--featured`;
- `catalog-layout`, `catalog-products`, `catalog-filters` — макет каталога, товары и фильтры;
- `order-dialog` — модальное окно с элементом `__title`;
- `order-form` — форма с элементами `__field`, `__label`, `__input`, `__select`, `__textarea`, `__checkbox`, `__hint`, `__actions`;
- `button` — кнопка с модификаторами `--primary` и `--secondary`;
- `advantages-list`, `aside-info`, `success-message`, `back-to-top` — дополнительные компоненты;
- `site-footer` — подвал сайта.


## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root`;
- единая шкала отступов;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus-visible`, `:disabled`;
- визуальная подсветка ошибочных полей через `aria-invalid`;
- структурированный файл `css/style.css`.
- применение Flexbox для компоновки элементов;
- базовое позиционирование элементов с помощью `relative`, `absolute` и `fixed`;


## Реализованные элементы интерфейса

- кнопки заказа в карточках товаров;
- модальное окно с формой заявки;
- поля формы: имя, e-mail, телефон, дата, тема, комментарий, согласие;
- базовая HTML-валидация;
- базовая JS-обработка формы;
- сообщение об успешной отправке.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `contacts.html` — контактная информация;
- `css/style.css` — файл стилей;
- `images/` — папка для изображений;
- `js/main.js` — JavaScript-логика проекта;
- `.gitignore` — список файлов, исключённых из Git;
- `README.md` — описание проекта.

## Дополнительные элементы

- `sitemap.xml` — простая карта сайта;
- Open Graph-теги — базовая разметка для отображения ссылок.

## Использование Flexbox и Grid

В проекте используются:

- Flexbox для основного меню;
- Flexbox для внутренней структуры карточек товаров;
- CSS Grid для сетки карточек;
- CSS Grid для страницы каталога с фильтрами и списком товаров.
